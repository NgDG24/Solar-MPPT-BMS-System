# Advanced Solar Power Path Manager with MPPT & BMS

- Author: Nguyen Duc Giang

## 📌 Project Overview
This project is a high-efficiency, robust hardware system designed to harvest solar energy (9V, 2.5A) and safely manage the charging/discharging process for a 1-Cell 18650 Li-ion battery. The design focuses on optimizing the "Power Path" through three specialized stages: High-Voltage Surge Protection, MPPT Buck Charging, and precision Battery Management.

## 🛠️ Advanced PCB Layout Techniques Applied
Designing a mixed-signal board that handles high current (3.2A), high-frequency switching (1.5MHz), and micro-volt level sensing requires strict adherence to design rules. This PCB was designed with the following industry-standard techniques:

*   **IPC-2221 Trace Width Compliance:** Power traces carrying up to 3.2A are designed using Polygon Pours (≥ 1.37mm) rather than standard traces to minimize IR drop and effectively dissipate heat generated by the MOSFETs and Inductor.
*   **Kelvin Sensing (4-Wire Measurement):** The current sense resistors (CSP/CSN pins on both LTC4162 and MAX17302) are routed using ultra-thin parallel differential pairs directly from the inner pads of the sense resistor. This prevents the 3.2A load current from interfering with the highly sensitive micro-volt measurements.
*   **Hot-Loop Minimization & Clearance:** The VOUT bypass capacitors for the LTC4162 are placed millimeters away from the IC to minimize parasitic inductance in the high-frequency loop. Additionally, strict clearance zones (> 0.5mm) are enforced around the high-impedance pins (SD, VDD, GATE) of the LTC4366 to prevent micro-amp leakage currents from causing false shutdowns [7].
